📋 INSTRUÇÕES DE SETUP:

1. OPÇÃO MAIS FÁCIL (abrir direto):
   - Extraia o ZIP
   - Clique duas vezes em "index.html"
   - Pronto! O jogo abre no navegador

2. OPÇÃO COM SERVIDOR (para PWA funcionar):
   
   Com Python 3:
   $ python -m http.server 8000
   
   Com Python 2:
   $ python -m SimpleHTTPServer 8000
   
   Com Node.js:
   $ npx http-server
   
   Depois acesse: http://localhost:8000

🎮 CONTROLES DO JOGO:

   WASD          = Movimento contínuo
   Mouse Click   = Mover para local clicado
   T             = Completar task próxima (quando perto)
   ESC           = Pausar
   D             = Debug mode (FPS, posições, etc)

🎯 OBJETIVO:

   1. Mova seu crewmate pela nave
   2. Aproxime-se das tasks (mostradas em amarelo)
   3. Aperte T para completar
   4. Veja os bots completando suas tasks também
   5. Acompanhe a barra de progresso no topo
   6. Objetivo: 100% de progresso em todas as tasks!

❓ FAQ:

P: Por que não vejo a progress bar mudando?
R: A progress bar se atualiza quando tasks são completadas. Pressione T perto
   de uma task, ou espere os bots completarem (você vai ver o diamante amarelo
   acima deles quando estiverem fazendo task).

P: Os bots não estão se movendo?
R: Eles se movem, mas pode ser lento no início enquanto navegam até as tasks.
   Use o debug mode (D) para acompanhar.

P: Posso jogar com amigos?
R: Essa versão é single-player com bots. Multiplayer é uma melhoria futura.

P: Como instalo como app?
R: Se acessar via servidor (não arquivo local), o navegador vai oferecer
   "Instalar app" ou "Add to home screen".
